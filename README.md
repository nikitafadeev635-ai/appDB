# CyberMG — Система складского учёта

Полноценное десктопное приложение для управления складским учётом, работой с базой данных, интеграцией со SmartShell и проверки расхождений администраторов.

## 🎯 Назначение

Централизованная система управления складом и товарооборотом для сети торговых точек:
- **6 точек**: Русская, Сахалинская, Трамвайная, Светланская, Ульяновская, Калинина
- **Интеграция**: База данных (MySQL) + SmartShell (GraphQL API) + Google Sheets

---

## 🚀 Возможности

### 📦 Управление товарами
- Просмотр и редактирование товаров по точкам
- Массовое добавление товаров в базу данных
- Создание товаров в SmartShell через GraphQL API
- Гибкие фильтры: по точкам, поставщикам, остаткам
- Подсветка отрицательных и нулевых остатков
- Поиск по названию и поставщику

### 📋 Журнал операций
- **взял** — взятие товара со склада
- **пришёл** — поступление товара
- **взял_периферию** — взятие периферии
- **пришла_периферию** — поступление периферии
- **убрал_периферию** — уборка периферии
- **изменение_штрихкода** — обновление штрих-кодов
- Фильтрация по типу операции и дате

### 🔍 Проверка расхождений
- Получение записей из `refStateDetailed` по администратору
- Диалог проверки ссылок и причин расхождений
- Пометка: **✓ Оправдано** / **✗ Не оправдано**
- Автоматическое обновление в Google Sheets:
  - **Минуса** уменьшается только при оправдании
  - **Спорный** уменьшается всегда после обработки
- Удаление обработанных записей из БД
- Бэкап таблицы перед обработкой

### ⚠️ Штрафы и корректировки
- Список штрафов администраторов
- Корректировки баланса

### 📄 Фактуры
- Обработанные фактуры из СБИС (`processed_factures`)
- Переданные фактуры (`processed_invoices`)
- Фильтрация по датам и номерам документов

### ❓ Отсутствующие товары
- Товары без маппинга в SmartShell
- `missing_smartshell_items`

### 📊 Статистика
- **По точкам**: количество товаров, отрицательные/нулевые остатки, средний остаток
- **По поставщикам**: количество товаров, средний остаток, охват точек

### 💾 Экспорт данных
- **CSV** — универсальный формат
- **Excel** — табличный формат (openpyxl)
- Экспорт текущей вкладки или всех данных

### 🎨 Визуал
- **Тёмная тема** — единый стиль для всего приложения
- **Фоновые изображения** — поддержка JPG и GIF
- **Анимация** — автоматическое проигрывание GIF-фонов
- **Дефолтный фон** — сохранение и загрузка по умолчанию
